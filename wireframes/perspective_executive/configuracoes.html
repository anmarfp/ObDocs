Regra Global de Envio de Alertas de Vencimento (RN-004)

Define a estratégia operacional de e-mails para todos os documentos da empresa.

Notificar Todos os Administradores

O e-mail de alerta de vencimento é enviado para todos os usuários com perfil Administrador. O campo "Responsável Específico" é ocultado do formulário.

Notificar Apenas o Responsável Atribuído

O e-mail é enviado exclusivamente para o endereço cadastrado no campo "Responsável" de cada documento. Exibe obrigatoriamente o campo no cadastro.
